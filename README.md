# AI vs ML vs Deep Learning

## Project Overview

This project provides a simple comparison of Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL).

The project explains their definitions, differences, learning approaches, data requirements, applications, and relationship with each other.

The comparison is implemented using Python and Jupyter Notebook.

## Objective

The main objective of this project is to build a clear understanding of the relationship between Artificial Intelligence, Machine Learning, and Deep Learning.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Markdown

## Concepts Covered

### Artificial Intelligence

Artificial Intelligence is the broad field of creating computer systems capable of performing tasks that normally require human-like intelligence.

Examples include:

- Virtual assistants
- Expert systems
- Game AI
- Recommendation systems

### Machine Learning

Machine Learning is a subset of Artificial Intelligence.

ML systems learn patterns from data and use those patterns to make predictions or decisions.

Examples include:

- Spam detection
- Fraud detection
- House price prediction
- Recommendation systems

### Deep Learning

Deep Learning is a subset of Machine Learning.

It uses multi-layer artificial neural networks to learn complex patterns from large amounts of data.

Examples include:

- Face recognition
- Speech recognition
- Image classification
- Autonomous driving
- Generative AI

## Relationship

The relationship can be represented as:

AI
└── Machine Learning
    └── Deep Learning

Therefore:

Deep Learning ⊂ Machine Learning ⊂ Artificial Intelligence

## Comparison

| Aspect | AI | ML | Deep Learning |
|---|---|---|---|
| Definition | Broad field of intelligent systems | Subset of AI that learns from data | Subset of ML using deep neural networks |
| Scope | Widest | Narrower than AI | Narrower than ML |
| Learning | Rules, logic, search, ML and DL | Statistical learning from data | Neural networks |
| Data | May or may not require large datasets | Usually requires training data | Usually requires large datasets |
| Examples | Virtual assistants, expert systems | Spam detection, recommendations | Image and speech recognition |

This project does not require an external dataset because it focuses on conceptual comparison.

## Output

The notebook produces:

- AI vs ML vs Deep Learning comparison table
- Real-world examples
- Relationship explanation
- Key differences
- Conclusion

## Conclusion

Artificial Intelligence is the broadest field concerned with creating intelligent systems.

Machine Learning is a subset of AI that enables computers to learn patterns from data.

Deep Learning is a specialized subset of Machine Learning that uses multi-layer neural networks to learn complex patterns.

Thus, the relationship is:

AI → ML → Deep Learning
